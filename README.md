## Environment configuration

Create a local `.env` file (do not commit it) using `.env.example` as a template. Configure `DATA_GOV_IN_API_KEY`, `OPENWEATHER_API_KEY`, `PLANT_ID_API_KEY`, and `OLLAMA_API_KEY` with your own credentials. The application loads `.env` at startup. Keep the values in your deployment provider's environment-variable settings when deploying.
